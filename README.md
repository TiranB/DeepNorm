# DeepNorm
DeepNorm is a layered data modeling project that applies advanced normalization techniques to transform raw datasets into deeply structured, multi-form relational models. It focuses on minimizing redundancy, enhancing data integrity, and building scalable database foundations.

## Normalization Layers Covered
| Normal Form | Purpose | Achieved In |
|-------------|---------|-------------|
| 1NF | Remove repeating groups and ensure atomicity | Raw → 1NF |
| 2NF | Remove partial dependencies | 1NF → 2NF |
| 3NF | Remove transitive dependencies | 2NF → 3NF |
